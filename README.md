# Casse-Croûte Rush — site web

Site promo du jeu coopératif **Casse-Croûte Rush** (GameMaker).

- `index.html` : page d'accueil
- `img/` : illustrations
- `jouer/` : la version HTML5 du jeu (remplacer le contenu par l'export HTML5 de GameMaker : `index.html` + dossier `html5game/`)

Hébergé sur Cloudflare Pages (aucune étape de build : dossier de sortie = racine).
